### Requirements

-   WP-CLI
-   PHP version >=8.0 (ideally 8.2)
-   Composer v2
-   Node v18

### First Time Setup

1. Run: `wp core download --locale=en_GB --skip-content`
2. Run: `composer install`
3. Rename theme folder
4. Change url to sitemap in robots.txt
5. CD to theme:
    1. Run: `composer install`
    2. Run `npm install`
6. Set up MAMP
7. Set up DB
8. Edit mix file to point to local MAMP url
9. You can either...
10. Rename the `wp-config-sample.php` to `wp-config.php` and edit the DB details there. Make sure to use a unuque db prefix NOT wp
11. Go to MAMP URL and do WP wizard set up
12. Run local `npx run watch` in theme to start dev...

### Local Install Steps

1. Run: `wp core download --locale=en_GB --skip-content`
2. Run: `composer install`
3. CD to theme:
    1. Run: `composer install`
    2. Run `npm install`
4. Set up MAMP
5. Install DB
6. Rename the `wp-config-sample.php` to `wp-config` and edit the DB details there.
7. Run local `npx run watch`

### Cloudways install

1. Set up 'Deployment via GIT' in Cloudways
2. Leave deployment path as public_html
3. Deploy repo
4. Run `composer install` in public_html
5. Run `composer install` in theme folder
6. Import DB
7. Edit wp-config.php as required eg DB prefix etc...
8. bish bash bosh!
